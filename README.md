# 우리사이 (사이봇)

서운한 마음을 다정한 데일리 미션으로 번역하는 커플 코칭 PWA. 정적 파일(`public/`)만으로 동작합니다.

- 라이브: https://jkangmin95-maker.github.io/saibot/ (main에 push하면 GitHub Pages Actions가 배포)
- 로그인: 카카오(Supabase Auth). 커플 연결은 `create_couple` / `join_couple` RPC, 테이블은 커플 멤버만 접근(RLS).
- 사이봇 대화: Supabase RPC `sai_chat` → Gemini. Gemini 키는 Supabase Vault(`urisai_gemini_api_key`)에만 있고, 클라이언트에는 anon 키만 있습니다.
- DB 변경은 순서대로: `supabase_schema.sql` → `supabase_migration_v8_kakao.sql` → `supabase_migration_v9_chat.sql` → `supabase_migration_v9_1_review.sql`(되돌리기: `_down.sql`) → `supabase_migration_v10_share_quiz.sql`(되돌리기: `supabase_migration_v10_share_quiz_down.sql`) → `supabase_migration_v11_paywall.sql`(되돌리기: `supabase_migration_v11_paywall_down.sql`). 테스트: `scripts/test_v8_rls.sql`, `scripts/test_v9_1_review.sql`, `scripts/test_v10.sql`, `scripts/test_v11.sql` (로컬 Postgres에서 한 번에: `scripts/run_local_sql_tests.sh`). v11.2: `supabase_migration_v11_2_book_click_paywall.sql`(되돌리기 `_down.sql`, v10.5 다음) — 결제 카드 책 링크 클릭 키 `paywall` 추가, 테스트 `scripts/run_local_sql_tests_v11_2.sh`.
- v10: 우리 온도 탭에 **우리 조합 카드**(둘 다 동의해야 공유, `share_consents`)와 **서로 맞히기 테스트**(`quiz.html`, 로그인 없음, anon RPC만) 진입 카드. 퍼널 숫자는 `private.funnel_events` (조회 SQL은 v10 마이그레이션 맨 아래).
- `index.html`과 `quiz.html`은 CDN 스크립트 없이 미리 빌드한 CSS(Tailwind 3.4.17, `app.css` / `quiz.css`)를 씁니다. 클래스를 바꾸면 `scripts/build_app_css.sh` 또는 `scripts/build_quiz_css.sh`로 다시 빌드하세요.
- v11: **심층 리포트(마음 날씨) + 결제 화면(아임웹 링크)**. 서버 플래그 `private.paywall_config`가 켜지고 가격·링크·열리는 시간이 모두 채워졌을 때만 보입니다(비밀방 안내 카드·한 줄·문구 교체도 같은 플래그). 결제 확인은 `select private.set_couple_paid('UR-XXXXXX');`(관리자). 켜는 SQL은 v11 마이그레이션 맨 위 주석. 리포트의 서운함 주제는 미션 기록 + 연인이 비밀방 [확인했어요](`consent_secret_report`)를 누른 뒤 플래그가 켜진 동안 쓴 글의 **주제 키만**(`private.secret_topic_tags`, 원문 저장 없음) 합쳐서 TOP 3. 연인의 동의 후 글이 3개 이상이고 주제별 2개 이상일 때만 반영(조건이 되는 순간 첫 리포트, 그 뒤로는 7일마다 갱신). 결제 버튼·리포트는 연인이 동의한 상태에서 **어제까지(KST)** 쓴 글만 세고, 모자라면 결제 버튼 대신 "리포트에 담을 이야기가 아직 모자라요. 조금 더 쌓이면 열 수 있어요.". 결제 확인 코드는 아임웹 상품의 필수 입력 옵션 "결제 확인 코드" 칸에 넣는다(배송 메모 아님). 수량 N개 = 30×N일. 결제는 **30일 이용권**(`private.couple_passes`, 다시 사면 이어서 30일, 환불·취소는 그 주문의 30일만 빠짐). 설정에서 [확인했어요]를 끌 수 있음(`withdraw_secret_report`). 비밀방 AI 호출은 사람당 KST 하루 20번(`private.secret_ai_daily_cap()`), 넘으면 "오늘은 여기까지 들을게요…" 안내만. 플래그가 꺼져 있으면 `sai_chat`이 Gemini에 보내는 요청은 v9.1과 똑같습니다(하루 상한은 항상 적용).
